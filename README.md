# Grace N Grow Marketing

Responsive, frontend-only marketing website built with the Next.js App Router, TypeScript, Tailwind CSS, Motion, and Lucide icons. All pages are statically rendered. No backend, database, authentication, or inquiry API is included.

## Run locally

- `npm install`
- `npm run dev`
- `npm run build`
- `npm start`

## Pages

Home, About, Services, Portfolio, Clients, and Contact.

## Update business details

Edit `lib/data.ts` to replace the WhatsApp number, email address, Instagram profile, location, service descriptions, and portfolio entries. WhatsApp uses `wa.me` click-to-chat; email uses `mailto:`. Update placeholder client information, metrics, testimonials, and case study details only when approved real content is available.

Portfolio entries are explicitly marked as concept work. Client names, campaign outcomes, and feedback are not invented.

## Deployment

The project is ready for a standard Vercel import. Connect the Git repository and use the default Next.js build settings.
